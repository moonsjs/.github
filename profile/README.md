# Moons (`@moonsjs`)

Zero-trust full-stack TypeScript framework — server code can never leak into the
client bundle.

- **Packages** (development berlangsung di repo masing-masing; Issues welcome):
  [`core`](https://github.com/moonsjs/core) ·
  [`server`](https://github.com/moonsjs/server) ·
  [`react`](https://github.com/moonsjs/react) ·
  [`vite`](https://github.com/moonsjs/vite) ·
  [`cli`](https://github.com/moonsjs/cli) ·
  [`mcp`](https://github.com/moonsjs/mcp)
- **Docs**: [`docs`](https://github.com/moonsjs/docs) — live di
  <https://docs.devmoon.net> (+ `/raw/**` markdown, `llms.txt`, `llms-full.txt`).
- **Cookbook** (pola kanonik, diuji CI):
  [`cookbook`](https://github.com/moonsjs/cookbook)

npm: <https://www.npmjs.com/org/moonsjs>
